בשפה פשוטה

אנחנו מחליפים רק את "הפנים" של האתר. השרת, המודלים, הנתונים והלוגין נשארים כמו שהם, ורק הקובץ שהדפדפן מקבל משתנה: במקום HTML אחד עם JavaScript משובץ, אפליקציית React שנבנית מראש לקבצים סטטיים ומקומטת לריפו, בדיוק כמו שהמודלים מקומטים היום. בכל שלב אפשר לחזור לממשק הישן בקומיט אחד. בסוף מקבלים ניווט אמיתי בין מסכים, ולידציה תוך כדי הקלדה, לקוח ש"עובר" ממסך התחזית לסימולטור, וקוד שקל להוסיף לו מסך שישי.

2. החלטות לאישור

D-M9-1 · הסטאק: Vite + React 18 + TypeScript, react-router, TanStack Query, react-chartjs-2, supabase-js, Vitest + Playwright

חלופות: Next.js (נפסל: צריך שרת Node, סותר "שירות אחד"); Recharts (נפסל להיקף הזה: כתיבה מחדש של 10 גרפים); Redux (מיותר: TanStack Query + context קטן מספיקים). למה: Vite בונה לקבצים סטטיים, react-chartjs-2 שומר את קונפיגורציות Chart.js הקיימות, TypeScript עם טיפוסים שנוצרים מ-/api/openapi.json נותן חוזה אמיתי מול ה-API. מחיר: Node על המחשב של דור (nvm), ועוד שפה בריפו.

D-M9-2 · הבנייה מקומטת: npm run build מקומית ← static/app/ בריפו; CI בונה מחדש ונכשל אם יש סטייה

חלופות: (א) Railpack עם Node + Python באותו image (נפסל: כבר היו שני תיקוני פריסה ב-Railpack, ובנייה בזמן deploy מוסיפה נקודת כשל); (ב) Actions בונה ומקמט בקומיט אוטומטי ל-main (נפסל: קומיטים של בוט ולולאות טריגר). למה: זה בדיוק העיקרון של D2 למודלים: מה שבריפו הוא מה שרץ, הפריסה דטרמיניסטית, ו-Railway לא צריך Node. CI מריץ npm ci && npm run build ומשווה ל-static/app/ (drift check) כך שאי-אפשר לשכוח לבנות. מחיר: קבצי build בריפו (~300KB, עם hash בשמות; הבעיה של המטמון מ-M7 נעלמת מבנית).

D-M9-3 · דו-קיום עד מבחן הזר: React ב-/app/, הממשק הישן נשאר ב-/static/dashboard.html; ההחלפה (/ ← /app/) ומחיקת הישן רק ב-M9c

למה: בכל רגע יש אתר שלם ועובד; אם משהו נשבר ביום השלישי, revert של PR אחד מחזיר את המצב הקודם. מחיר: שלושה ימים עם שני ממשקים בריפו.

D-M9-4 · שפת הממשק: אנגלית, מבנה RTL-ready (CSS logical properties, dir על השורש)

למה: תיק עבודות באנגלית; עברית למייסד היא תוספת של שעתיים-שלוש כשיהיה צורך, ולא צריך לשבור כלום בשבילה.

6. סיכונים ומה עושים איתם

  • Node לא מותקן. דור מריץ: brew install nvm → nvm install 20. עד אז אי-אפשר להתחיל; זה הצעד הראשון של יום 1.
  • הבנייה ב-CI שונה מהמקומית (גרסאות Node/npm). .nvmrc + package-lock.json + npm ci; ה-drift check תופס כל הבדל לפני המיזוג.
  • הפניית / משנה את מה שמשתמש רואה ראשון. נעשית רק ב-M9c ורק אחרי מבחן הזר; revert של קומיט אחד מחזיר.
  • ההרשאות של Claude Code חסמו בעבר הזרקת session לדפדפן. לצילומים ולבדיקות חיות דור מחובר לאתר בטאב שלו (עבד ב-M7–M8).
  • גלישת היקף. הכל מחוץ לטבלת "נכנס" נרשם כ-M10 ולא נכנס לשום PR של M9.
  • הזמן. אם יום 2 מתארך, Budget עובר ליום 3 ו-M9c מתקצר (Playwright נשאר, GIF יכול לחכות). לא מוחקים את הישן בלי מבחן זר.
